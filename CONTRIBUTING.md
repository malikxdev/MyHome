# 🤝 Contributing to My Home

First of all — thank you for wanting to help! 🙌 My Home is a small, friendly project, and every contribution, big or small, makes it better for everyone.

Before you jump in, please take two minutes to read this. It keeps things smooth for you and for everyone else.

---

## ✅ Step 1: Join the Discord server (required)

We plan and discuss everything in our Discord server. This is where ideas get shaped, questions get answered, and nobody works on the same thing by accident.

**👉 [Join the My Home Discord](https://discord.gg/Rt5eXrjw4C)**

If you want to add a feature, change something, or even just ask whether an idea is a good one, come talk to us first. It saves you time and makes sure your work actually fits the project.

---

## 💡 Step 2: Pick one thing to work on

- **Work on one feature at a time.** Please don't juggle multiple ideas in a single pull request — it makes review slower for everyone.
- Say what you're working on in Discord so nobody else starts the same thing.
- Keep changes focused: a small, clean pull request is a thousand times easier to review than a big messy one.

---

## 🛠 How to contribute

1. **Fork** the repository and clone it to your machine.
2. **Create a branch** for your work (e.g. `feature/weather-animations`).
3. **Make your changes**, keeping the code style consistent with the rest of the project.
4. **Test** what you changed — make sure it runs and nothing else breaks.
5. **Commit** with a clear, short message describing what you did.
6. **Push** your branch and open a **pull request** against `main`.

> Note: this repository requires changes to go through a pull request — you can't push directly to `main`.

---

## 📝 Writing and style

- Write in **clear English** — we're a global community, so keep it simple and friendly.
- Emojis and personality are very welcome! 😄 We like a little emotion in our docs and messages.
- Follow the existing code style in the project. If you're unsure, ask in Discord.

---

## 💬 Community expectations

- Be kind and respectful to everyone.
- Give constructive feedback, and take it gracefully when it's given to you.
- Questions are always welcome — there are no silly ones.

---

## 🙏 Again, thank you

Every contributor makes My Home a little better. We can't wait to see what you build. See you on Discord!
